Acheter POS - Android Wrapper

This project has been converted into a Native Android (Kotlin) codebase and is ready for export.

The web preview cannot run native Android code directly. To get your APK:

  1. Click Export to GitHub / Download ZIP in the AI Studio settings menu.
  2. If exporting to GitHub, go to the Actions tab in your repository.
  3. The automated workflow will build the Android project.
  4. Download the built app-debug.apk file to your tablet.

* Note: The source code is located in the /app directory and the GitHub Action is in .github/workflows.
